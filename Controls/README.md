# Controls

Reusable WinUI controls are grouped by purpose:

- `Cards/AppCard` provides shared surfaces, header/footer slots, commands, keyboard activation, and hover/pressed feedback.
- `Cards/MetricCard`, `AccountCard`, `CategoryCard`, and `BudgetProgressCard` cover finance-specific summaries.
- `Common/SectionHeader`, `EmptyState`, `AmountText`, `TransactionListItem`, and `LoadingSkeleton` cover repeated page patterns.
- `Charts/ChartLegend` provides a theme-aware legend model and view for the chart work in Phase 5.
