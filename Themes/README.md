# Themes

Application-wide semantic resources are split by concern:

- `Colors.xaml` defines Light, Dark, and HighContrast brushes plus the chart palette.
- `ThemeResources.xaml` defines spacing, padding, radii, and layout metrics.
- `Typography.xaml` defines page, section, metric, and secondary text styles.
- `Controls.xaml` defines shared card, settings-group, and accent-button styles.
